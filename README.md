# IPL Analysis Dashboard | Power BI

An interactive Power BI dashboard for exploring Indian Premier League (IPL) statistics across seasons **2008–2025**.

## Project Overview

This project uses Microsoft Power BI to present IPL statistics in an interactive dashboard. Users can explore season-level metrics, team standings, and player achievements using the available report filters and visuals.

- **Project type:** Data analytics portfolio project
- **Tool:** Microsoft Power BI
- **Analysis period:** 2008–2025
- **Main file:** `IPL Analysis.pbix`

## Project Folder Structure

The local project folder is organised as follows:

```text
IPL-Analysis-Power-BI/
```

- **`Dashboard video.mp4`** — video demonstration of the dashboard and its interactive season filter.
- **`IPL Analysis.pbix`** — the Power BI report file.
- **`README.md`** — project documentation, including the overview, key features, and instructions for opening the dashboard.

## Dashboard Features

- **Interactive season filter** to explore available seasons.
- **KPI cards** for tournament metrics shown in the dashboard, such as matches, teams, sixes, fours, and centuries.
- **Orange Cap statistics** for batting performance.
- **Purple Cap statistics** for bowling performance.
- **Team standings and points table** for comparing teams.
- **Interactive data visualisations** to make IPL statistics easier to explore.

The exact metrics and analysis depend on the source data and measures included in the Power BI report.

## How to Open the Dashboard

1. Download `IPL Analysis.pbix` from this repository.
2. Open the file using Microsoft Power BI Desktop.
3. If Power BI requests the original data source or reports missing data, reconnect the dataset on your local computer and update the data-source paths if necessary.
4. Use the season filter and interact with the visuals to explore IPL statistics from 2008 to 2025.

**Note:** The source dataset is not included in this repository. Dashboard functionality may depend on the data embedded in the `.pbix` file or the availability of the original data source.
